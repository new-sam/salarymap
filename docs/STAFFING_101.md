# 스태핑 사업 이해하기

레포 안 문서들을 모아 정리. 각 항목 끝에 근거 파일 표기.

## 1. 한 줄

한국 회사에 베트남(및 인도·호주) 인재를 붙여주고, 그 사람 인건비를 매달 받는 사업.
채용 대행이 아니라 "팀원 한 명을 구독처럼 쓰는" 형태. → `docs/VN_KICKOFF_PREP.md`, `docs/STAFFING_LINKEDIN_DM_GUIDE.html`

## 2. 사업이 두 개다 (헷갈리기 쉬움)

| | 스태핑 (KR) | FYI (VN) |
|---|---|---|
| 고객 | 한국 기업 | 베트남 현지 기업 |
| 파는 것 | 베트남 인재를 팀원으로 붙여줌 | 채용 플랫폼(공고+ATS+헤드헌팅) |
| 돈 받는 법 | 월 구독료 (월 99만원~) | 성사 수수료 연봉의 5%(베이직)·7%(프리미엄) |
| 지금 상태 | 매출 파이프 1 — 영업 중 | 매출 파이프 2 |

공통 재료는 **인재 풀**이다. 인재는 전부 FYI(salary-fyi.com) 한 파이프로 모으고, 그 풀을 두 사업이 같이 쓴다. → `docs/ORG_STRUCTURE.html`, `docs/fyi-staffing/FYI_기업정책.md`

## 3. 고객이 사는 이유 세 가지

- **싸다** — 같은 5년차인데 직군별 32~58% 저렴. 개발자 월 470→319만원, 디자이너 350→186만원, 마케터 400→167만원.
- **빠르다** — 공고 올리고 2~3개월 기다리는 대신, 조건만 주면 평균 7.2일 안에 1차 면접.
- **안심된다** — 호치민 오피스 출근 + 한국인 매니저, 자동번역으로 한국어 소통, 성과 안 나오면 교체.

→ `docs/VN_KICKOFF_PREP.md`, `deck/index.html`

## 4. 파는 방식

- 진행 4단계: ① 채용 조건 전달 → ② 후보 발굴·검증 → ③ 면접 → ④ 입사
- 채용 수수료 없음, 2주 무료 체험 후 결정, 언제든 해지 → 고객 입장에서 위험이 거의 없게 설계
- "JD / AI 인터뷰 / EOR"은 내부 용어. 고객에게 나가는 글에는 안 쓴다.

→ `docs/VN_KICKOFF_PREP.md`, `docs/STAFFING_LINKEDIN_ABTEST_V2.html`

## 5. 누구한테 파나

우선순위 세 갈래:
1. 개발·디자인 채용 중인 10~100인 회사 (공고 열어놨는데 2달째 못 뽑음)
2. 외주를 반복해서 쓰는 회사 (외주비 > 베트남 정규 팀원 월급)
3. 동남아 진출 관심 있는 커머스·소비재

리드 고르는 축은 두 개, **적합도 × 시급성**. 우리가 잘 뽑아주는 직군인가 × 공고가 오래 열려 있거나 반복 게재되는가. 상3·중2·하1로 곱해 점수 높은 순으로 발송.

말 거는 사람: 50인 이하는 대표에게 직접, 그 이상은 개발 리더나 경영지원 책임자. 단 결국 돈 문제라 대표가 읽어도 통하게 쓴다. → `docs/VN_KICKOFF_PREP.md`, `docs/STAFFING_DAILY_DASHBOARD.html`

## 6. 어떤 말이 먹혔나

메시지 실험 결과(대시보드 집계):

- 🔥 "베트남 시장" — 회신 16%
- 🔥 "가격 — 인건비 1/3" — 회신 9%
- 🗑 "월 99만원 / 상위 5%" — 회신 0%, 폐기
- 실험 중 "무료 컨설팅 CTA" — 3%

타깃 실험: 잡코리아 개발자 구인 중 10%, 그룹바이 스타트업 10%, 멋사 보유 리스트 2%(폐기).

캠페인 메시지 3종은 A 비용 → 반응 없으면 B 속도 → 미팅 후 망설이면 C 안심. 한 메일에 셋을 다 넣지 않는다. → `docs/STAFFING_DAILY_DASHBOARD.html`, `docs/VN_KICKOFF_PREP.md`

## 8. 조직과 숫자 관리

퍼널 3단: **기업 모객(유입) → 인재 모객 → 매칭·클로징**

- 유입 (스태핑): 남영훈·전준현 / KPI = 개설된 단톡 수(JD 확보)
- 인재 (FYI): 남영훈 DRI / KPI = 지원 수, 리드타임, 채용 중 FYI 비율
- 매칭 (스태핑): 전준현 DRI / KPI = 리드타임, 채용 전환율

월 클로징 딜 = 단톡 수 × 전환율. 목표 숫자는 아직 빈칸.

영업 현황은 DB로도 관리한다 — `cold_outreach` 테이블에 deal_stage(lead/contact/meeting/won/hold/lost), next_action, meeting_at, deal_value 등. 발송 상태(status, 자동)와 영업 단계(deal_stage, 수동)를 분리. → `docs/ORG_STRUCTURE.html`, `supabase/migrations/20260810_cold_outreach_deal_board.sql`

원칙은 하나 — 근거 시트에서 눈으로 확인 안 된 숫자는 메일·광고에 안 넣는다. → `docs/VN_KICKOFF_PREP.md`

## 10. 가격이 맞는지 검증한 것 (FYI 7% 기준)

KTC 2026 실채용 데이터로 계산한 CPH(1명 뽑는 데 드는 실제 비용):

```
CPH = 유료 공고 총지출 ₫50.0M ÷ 성사 5명 ÷ 근속률 0.92 ≈ ₫10.9M / 명
```

손익분기 연봉 = ₫10.9M ÷ 7% = **₫156M(월 ~₫13M)**. 이 아래면 7%가 직접 뽑는 것보다 싸고, 위면 비싸다. 주니어 0.7배(합리적) / 미드 1.8배(높음) / 시니어 3.1배(너무 높음).

즉 정률 7%는 저연봉 구간용이고, 고연봉 구간은 가격을 다시 봐야 한다. → `docs/CPH_PRICING.md`
